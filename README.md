# Deep Learning Spam Classifier

## Project Overview
This project uses Deep Learning techniques to classify SMS messages as Spam or Ham.

## Technologies Used
- Python
- TensorFlow
- Keras
- Pandas
- NumPy
- Matplotlib

## Deep Learning Model
- LSTM Neural Network

## Features
- Tokenization
- Padding
- LSTM Model Training
- Accuracy Visualization
- Saved Trained Model

## Result
The model achieved high accuracy in spam message classification.
